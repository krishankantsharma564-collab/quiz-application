# Quiz Application

A console-based Quiz Application developed in C that displays multiple-choice questions, accepts user answers, evaluates responses automatically, and calculates the final score and percentage.

## 📌 About the Project

This project demonstrates the practical implementation of fundamental C programming concepts such as Arrays, Structures, Loops, and Conditional Statements. The application presents a series of quiz questions, validates user input, checks answers, and displays the final result with performance remarks.

## ✨ Features

- Multiple-choice quiz system
- Stores questions using structures and arrays
- Input validation for user answers
- Automatic answer checking
- Score and percentage calculation
- Performance-based remarks
- Simple console interface

## 🛠 Technologies Used

- C Programming Language
- GCC Compiler

## 📚 Concepts Used

- Arrays
- Structures
- Loops (`for`, `do-while`)
- Conditional Statements (`if-else`)
- User Input and Output

## 🚀 How to Run

### Compile the Program

```bash
gcc quiz.c -o quiz
```

### Run the Program

```bash
./quiz
```

## 📋 Sample Questions

1. Which symbol is used to end a statement in C?
2. Which header file is required for `printf()`?
3. Which data type stores a decimal number?
4. Which loop is used when the number of repetitions is known?
5. What is the index of the first element of an array in C?

## 📊 Scoring System

| Percentage | Remark |
|------------|---------|
| 80 - 100 | Excellent |
| 60 - 79.99 | Good |
| 40 - 59.99 | Average |
| Below 40 | Needs Improvement |

## ⚠️ Limitations

- Scores are not saved permanently
- Supports only multiple-choice questions
- No graphical user interface
